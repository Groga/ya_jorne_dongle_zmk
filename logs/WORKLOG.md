## Исходная проблема

Клавиатура работает, но раскладка «уезжает» — печатаются не те символы,
что нанесены на клавишах. Часть клавиш не откликается вообще.

## Итоговый диагноз (по порядку глубины)

Проблема оказалась многослойной. Все находки подтверждены **реальным
USB-логом** `kscan_matrix_read` с платы, а не догадками по картинке.

### 1. Не собирался лог левой половины
В корневом `build.yaml` (именно его читает GitHub Actions) у `jorne_left`
не было `snippet: zmk-usb-logging`. `CONFIG_ZMK_LOG_LEVEL_DBG=y` в конфиге
был, но выводить лог было некуда → отладка левой половины шла «вслепую».
**Исправлено:** добавлен сниппет логирования для левой половины.

### 2. Неверные пины столбцов (col-gpios) на левой половине
Старая версия `jorne_left.overlay` использовала сырые пины `&gpio0/&gpio1`,
которые нельзя сверить с шёлкографией платы. Внутри пряталось два бага:
- `COL 4 = P0.28` — **такого пина нет на разъёме nice!nano вообще**
  (проверено по `arduino_pro_micro_pins.dtsi` из исходников ZMK). Сигнал
  уходил в никуда → клавиши R/F/V были мертвы.
- `COL 5 = P0.09` (= пин NFC-антенны) — тоже оказался не тем пином.

**Исправлено:** весь overlay переведён на метки `&pro_micro` (как на
правой половине). Финальная карта столбцов подтверждена логом:
```
COL 0..6 = pro_micro 21, 20, 19, 18, 15, 14, 16
         = ` Q W E R T + внешняя колонка
```
`row-gpios` = `pro_micro 4/5/6/7` — подтверждены логом инициализации
(P0.22 / P0.24 / P1.00 / P0.11).

### 3. Один из рабочих пинов — тоже NFC
После перевода на `&pro_micro` COL 4 стал `D16 = P0.10` — это **второй**
NFC-пин nRF52840. Поэтому опция `CONFIG_NFCT_PINS_AS_GPIOS=y` в
`jorne_left.conf` осталась нужной (но уже по другой причине, чем её
добавляли изначально).

### 4. ГЛАВНАЯ причина «уезжания» — matrix_transform
`jorne_common.dtsi` описывал матрицу не так, как она разведена физически.
Лог по 4 клавишам расставил всё по местам:

| Нажата физически | Электрически | Старый transform ждал |
|------------------|--------------|-----------------------|
| Win              | (3,0)        | большой палец Tab → Win печатал Tab |
| Tab              | (3,3)        | нет в карте → «Not found» → мёртв |
| Space            | (3,4)        | нет в карте → мёртв |
| Enter            | (3,5)        | нет в карте → мёртв |

**Вывод:** внешняя колонка (Win/Ctrl/Alt) и три больших пальца
(Tab/Space/Enter) физически сидят все вместе в электрическом ряду 3,
столбцы 0..5. Home-ряд и нижний ряд занимают ряды 1/2, столбцы 0..4.

**Исправлено (v4.0, ПОДТВЕРЖДЕНО логами — все 22 клавиши левой половины):**
Полная электрическая карта левой половины по логу:
```
ряд 0:  `=(0,0) Q=(0,1) W=(0,2) E=(0,3) R=(0,4) T=(0,5)
ряд 1:  Ctrl=(1,0) A=(1,1) S=(1,2) D=(1,3) F=(1,4) G=(1,5)
ряд 2:  Alt=(2,0) Z=(2,1) X=(2,2) C=(2,3) V=(2,4) B=(2,5)
ряд 3:  Win=(3,0)       Tab=(3,3) Space=(3,4) Enter=(3,5)
```
Оказалось, что от оригинала (v2.0) реально нужно было поменять только две
вещи: Win (RC(0,6) -> RC(3,0)) и большие пальцы (RC(3,0..2) -> RC(3,3..5)).
Внешняя колонка Ctrl/Alt сидит в начале своих рядов (1,0)/(2,0), а НЕ в
ряду 3 — промежуточная догадка v3.0 это перепутала и была откачена.
Правая часть карты пока не тронута — правую половину предстоит проверить
логом тем же способом.

### 5. Правая половина (по логам, 2026-09-03)
Левая половина проверена — печатает штатно. По правой снят лог по рядам:
```
ряд 0:  Y=(0,0) U=(0,1) I=(0,2) O=(0,3) P=(0,4) [=(0,5) ]=(0,6)
ряд 1:  H=(1,0) J=(1,1) K=(1,2) L=(1,3) ;=(1,4)        '=(1,6)
ряд 2:  N=(2,0) M=(2,1) ,=(2,2) .=(2,3) /=(2,4)        \=(2,6)
пальцы: НЕ давали событий вообще (ряд не сканировался)
```
Найдено и исправлено:
- **`[` (LBKT) мертва** — сидит в столбце 5 = `pro_micro 16 = P0.10` = второй
  NFC-пин. Добавлен `CONFIG_NFCT_PINS_AS_GPIOS=y` в `jorne_right.conf`.
- **`'` и `\` не работали** — внешние клавиши физически в столбце 6
  (transform col 13), а карта заводила их в col 12. Исправлено:
  `RC(1,12)→RC(1,13)`, `RC(2,12)→RC(2,13)`.
- **Ряд больших пальцев молчал полностью** — пин строки 3 был `D8 (P1.04)`,
  а на левой (рабочей) половине строки идут по `D4/D5/D6/D7`. Половины
  делят один набор пинов → на правой row3 тоже `D7`. Исправлено в
  `jorne_right.overlay` (`pro_micro 8 → 7`). Столбцы пальцев в карте
  выставлены `RC(3,10)/(3,11)/(3,12)` по аналогии с левой (гипотеза,
  требует финальной проверки нажатием).

### 6. Правая половина — финал (по фото + логам)
Пользователь прислал фото раскладки, обведя красными овалами ДВЕ отдельные
клавиши Win (левую и правую). Это прояснило последние две ошибки в карте
правого верхнего ряда:
- **`[` (поз.12)** физически в столбце 6, а карта заводила её в столбец 5
  (который на правой половине вообще не используется) → `[` не работала.
  Исправлено: `RC(0,12) → RC(0,13)`.
- **Отдельная Win (поз.13, = RWIN/`]`/F12/Reset)** физически в ряду больших
  пальцев `(3,6)` — зеркальная пара левой Win в `(3,0)` — а карта заводила
  её в верхний ряд `(0,6)`. Исправлено: `RC(0,13) → RC(3,13)`.
- Большие пальцы Esc/Bspc/Del подтверждены в столбцах 0,1,2 → карта
  возвращена к `RC(3,7)/(3,8)/(3,9)`.

Важно: раскладка осталась **44-клавишной**, лишних позиций не добавляли.
Столбец 5 правой половины (P0.10/NFC) по факту не используется — опция
`CONFIG_NFCT_PINS_AS_GPIOS` в `jorne_right.conf` не нужна, оставлена как
безвредная страховка.

## Статус: ГОТОВО
Клавиатура печатает корректно на обеих половинах, логи отключены, ZMK Studio
работает. Прошивки в `../firmware/`.

### Подключение к ZMK Studio (памятка)
1. Подключить донгл по USB к компьютеру.
2. Открыть https://studio.zmk.dev (Chrome/Edge — нужен WebSerial),
   либо приложение ZMK Studio.
3. Connect → выбрать COM-порт донгла.
4. Разблокировать раскладку комбо: одновременно Tab (левый большой палец)
   + Del (правый большой палец).
5. После этого раскладку можно менять прямо в Studio без пересборки.

## Как собрать прошивку локально (памятка)

Окружение уже развёрнуто в песочнице: `west` + Zephyr SDK 0.17.0
(`arm-zephyr-eabi`) + `protobuf-compiler` (нужен для ZMK Studio).
Команда сборки одной цели:
```
west build -d build/left -b nice_nano/nrf52840/zmk -s zmk/app -- \
    -DSHIELD=jorne_left -DZMK_CONFIG=<repo>/config \
    -DSNIPPET=zmk-usb-logging -DCMAKE_PREFIX_PATH=<repo>/zephyr/share
```
